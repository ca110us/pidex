# Pidex: four icon directions

This round explored directions; direction A, "Index P", was chosen and lives
in `../icon/`. Every shape is an original, editable SVG path.

- A, Index P: the letter P as an index with an opening.
- B, Snap fit: a photo and its place.
- C, Dex fold: a dex that grows.
- D, The find: a subject in a recognition frame.

Each folder holds Light, Dark and Tinted colourways as SVG. App icons are
opaque, full-bleed squares; the rounded corners in the overview are for
preview only. Tinted only suggests the single-colour look; the system applies
the colour the user picks.

Overview: `pidex-four-directions.svg` (open it in a browser).

How they were made: drawn directly as vectors, with PNGs rendered from the
same SVGs; no embedded bitmaps and no image generation models.

Brief: Pidex recognizes what is photographed and files it as the photo is
taken. Following the user's preference for a Grok or X style (black and
white, simple, sharp), the round explored four outlines: the initial P, a
photo dropping into place, the folded pages of a dex, and recognition of a
subject. One bold outline, generous space, no text and no medical symbols;
black-and-white and single-colour variants, checked at 60×60.
